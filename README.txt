Partner Calendar - 공유형 웹버전

기능
- 여러 사람이 같은 웹주소로 접속해 동일한 일정/참석자/후기를 공유
- 최초 접속 시 회사명 / 직책 / 이름 입력
- 행사 종류별 색상: HQ Visit / 미팅 / 학회 / 교육 / KOL Lecture / 기타
- 여러 날짜 행사 등록
- 참석 / 불참
- 참석자 목록
- 후기 및 사진
- 관리자만 행사 등록 / 수정 / 삭제
- 기본 관리자 PIN: 2580

컴퓨터에서 실행
1) Node.js 설치
2) 이 폴더에서 터미널 실행
3) npm install
4) npm start
5) 브라우저에서 http://localhost:3000 접속

외부 대리점과 실제 공유하려면 이 폴더를 Render/Railway 같은 Node.js 호스팅 서비스에 올리면 됩니다.
실서비스에서는 반드시 ADMIN_PIN 환경변수를 다른 번호로 변경하세요.
